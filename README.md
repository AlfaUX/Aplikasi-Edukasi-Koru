# Koru - Aplikasi Edukasi Berbasis Augmented Reality

## 📖 Tentang Proyek

Koru adalah aplikasi pembelajaran interaktif berbasis Android yang dikembangkan menggunakan Unity Engine dan teknologi Augmented Reality (AR). Aplikasi ini dirancang untuk membantu proses pembelajaran dengan menghadirkan visualisasi objek 3D secara interaktif sehingga materi lebih mudah dipahami dan menarik bagi pengguna.

Dengan memanfaatkan teknologi AR, pengguna dapat melihat objek pembelajaran secara real-time melalui kamera perangkat, memberikan pengalaman belajar yang lebih modern dan efektif dibandingkan metode pembelajaran konvensional.

## 🚀 Cara Menjalankan Proyek

### Persyaratan

- Unity Hub
- Unity 2022.x
- Android Build Support
- Vuforia Engine

### Langkah Instalasi

1. Clone repository ini.

```bash
git clone https://github.com/AlfaUX/Aplikasi-Edukasi-Koru.git
```

2. Buka proyek menggunakan Unity Hub.

3. Pastikan package dan dependency telah terpasang.

4. Buka scene utama aplikasi.

5. Jalankan menggunakan tombol **Play** atau build ke perangkat Android.
